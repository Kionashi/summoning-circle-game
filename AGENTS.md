# Summoning Circle Game

## About me

I am learning Godot 4 and GDScript.

My goal is to understand the engine, not just finish the project.

Treat me like a developer with good programing background who wants to learn Godot.

## Coding style

- Prefer idiomatic Godot solutions.
- Keep code simple and readable.
- Explain why you chose a solution.
- Mention alternative approaches when appropriate.
- Don't introduce design patterns unless they clearly solve the current problem.

## Working style

- Before making significant changes, explain your plan and ask for confirmation.
- Make changes incrementally rather than rewriting large parts of the project.
- If you notice a potential issue, point it out and explain why.

## Godot

- Use Godot MCP tools whenever interacting with scenes or the running editor.
- Prefer editing scenes through MCP rather than manually modifying `.tscn` files.
- Follow Godot 4 best practices.
- Prefer signals, nodes, and composition over complex inheritance when appropriate.

## Responses

- Expand explanations when I ask "why" or "can you explain."
- If I'm asking a beginner question, don't assume prior knowledge.
